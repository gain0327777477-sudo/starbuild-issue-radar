# 스타빌드 이슈레이더

경제·주식·금리·부동산·개발 이슈를 모아서 **블로그 글감(소재 패킷)** 으로 만들어 주는 핸드폰용 웹앱입니다.
이슈마다 "사람들이 지금 찾는가(집객)"와 "내 블로그 카테고리로 이어지는가(사업 연결)"를 점수로 매겨 보여줍니다.

> 이 문서는 단계마다 채워 갑니다. 지금은 **5단계(핸드폰 화면)까지** 끝난 상태입니다.
> GitHub 자동 수집·키 등록·홈 화면 설치는 6단계에서 추가됩니다.

---

## 1. 처음 한 번만: 설치

이 PC에는 이미 설치가 끝나 있습니다. 다른 PC에서 새로 할 때만 아래를 따라 하세요.

1. Python 3.12 이상 설치 (https://www.python.org → Download → 설치 화면에서 **Add python.exe to PATH** 체크)
2. 이 폴더에서 PowerShell 을 열고 아래 두 줄 실행

```bash
python -m venv .venv
```

```bash
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

---

## 2. 수집하기 (뉴스 모으기 → 점수 → 오늘 추천 → 소재 패킷)

**`수집_실행.bat` 를 더블클릭**하세요. 약 1분 걸립니다. 창에 이렇게 나오면 성공입니다.

```
✅ 정책브리핑: 900건 …
✅ 구글 뉴스: 557건 …
오늘 쓸 글 추천:
   [집객형 (주식·경제)] …
```

- 네이버 키가 없어도 구글 뉴스·정책브리핑·내 블로그만으로 동작합니다(6단계에서 키를 넣으면 네이버 뉴스가 더해짐).
- 한 곳이 실패해도 나머지는 계속 모읍니다. 실패한 곳은 화면 위에 빨간 칩으로 보입니다.

---

## 3. 미리 보기 — 이 PC와 핸드폰에서 화면 보기 (6단계 전)

1. 먼저 위 2번(수집)을 한 번 하세요.
2. **`미리보기_실행.bat` 를 더블클릭**합니다. 창에 주소가 두 개 나옵니다.

```
  · 이 PC 에서     : http://localhost:8000
  · 핸드폰에서     : http://192.168.219.107:8000   ← 같은 와이파이에 연결된 핸드폰 인터넷 주소창에 입력
```

3. 핸드폰을 **PC와 같은 와이파이**에 연결하고, 핸드폰 인터넷(크롬·삼성 인터넷) 주소창에 위 "핸드폰에서" 주소를 그대로 입력합니다.
   (숫자는 PC·공유기에 따라 다릅니다. 창에 나온 주소를 쓰세요.)
4. 다 봤으면 검은 창에서 `Ctrl + C` 를 누르거나 창을 닫으면 꺼집니다.

### ⚠ 미리 보기(HTTP)에서는 안 되는 것

핸드폰 브라우저는 보안 때문에 **HTTPS 주소에서만** 아래 기능을 허용합니다.
미리 보기 주소(`http://192.168…`)는 HTTPS가 아니라서 핸드폰에서는 이 기능들이 동작하지 않고, 화면 맨 위에 파란 **"미리 보기(HTTP) 모드"** 안내가 뜹니다.

| 기능 | 미리 보기(HTTP) | 6단계 이후(HTTPS, GitHub Pages) |
|---|---|---|
| 이슈 보기·검색·지역 거르기·점수 근거 | ✅ | ✅ |
| 소재 패킷 보기, ① 네이버용 복사, ② 원고 요청문 복사 | ✅ | ✅ |
| 저장함(기기 안 저장) | ✅ (주소마다 따로 저장됨) | ✅ |
| ③ 공유 버튼(Claude 앱·카카오톡으로 보내기) | ❌ 버튼이 숨겨짐 | ✅ (안드로이드) |
| 홈 화면에 설치 | ❌ | ✅ |
| 오프라인(인터넷 끊겨도 저장본 보기) | ❌ | ✅ |

> PC의 `http://localhost:8000` 은 예외적으로 브라우저가 안전한 주소로 취급해서 오프라인 동작까지 시험해 볼 수 있습니다.

### 핸드폰에서 안 열릴 때

- **Windows 방화벽 창**이 떴다면 **'개인 네트워크'만 허용**을 눌러 주세요. (이미 '취소'를 눌렀다면: 시작 → "Windows Defender 방화벽" → "앱 허용" → python 의 '개인' 체크)
- 핸드폰이 **같은 와이파이**인지 확인하세요(모바일 데이터 X, 게스트 와이파이 X).
- 회사·카페 와이파이는 기기끼리 접속을 막는 경우가 많습니다. 집 와이파이에서 해 보세요.
- 주소 끝의 `:8000` 까지 입력했는지 확인하세요.

## 4. 화면 사용법

- **아래쪽 탭**: 오늘 추천 / 증시·경제 / 금리·대출 / 숙박·관광 / 부동산·상권 / 지역개발 (엄지로 누르기 쉽게 아래에 고정)
- **카드**: 분야, 집객 ★1~3, 연결 배지(예: → 대출 판단), 관련 기사 수, 짧은 배지
  - 방향: 원화 강세·금리 동결·증시 하락 등 / 단계: 건의·요구·계획·착공·개통 등 / 호재·악재·양면 / 지역(누르면 그 지역만 보기)
  - '점수 근거 · 연결 논리'를 누르면 몇 점을 왜 받았는지와 관련 기사 목록이 보입니다.
- **소재로 저장** → 소재 패킷 화면이 열리고 저장함에 저장됩니다.
  - **① 네이버용 텍스트 복사**: 글감 정리본(제목 후보·키워드·글 틀·상담 안내·출처). 마크다운 기호 없음
  - **② 원고 작성 요청문 복사**: Claude 앱에 그대로 붙여 넣으면 원고가 나오는 지시문
  - **③ 공유**: 안드로이드에서 Claude 앱·카카오톡으로 바로 보내기 (지원하는 기기에서만 버튼이 보임)
- **저장함**: 저장한 소재는 **이 기기 안에만** 보관됩니다(서버로 보내지 않음). 브라우저 데이터를 지우면 함께 지워집니다.
- **설정**: 밝게/어둡게, 글씨 크기(보통 17px / 크게 19px), 수집 상태(소스별 성공·실패와 원인)
- 위쪽 경고
  - 🟥 **수집이 멈췄습니다**: 마지막 수집이 3시간 넘게 지났을 때
  - 🟨 **오프라인 · 저장된 데이터**: 인터넷이 안 돼 마지막 저장본을 보여줄 때

## 5. 설정 파일 (직접 고치는 곳: `config` 폴더)

| 파일 | 내용 |
|---|---|
| `office.yaml` | 상호·대표·등록번호·**소재지**·연락처 (연락처는 이 파일 한 곳에서만) |
| `blog_categories.yaml` | 블로그 카테고리와 주소 |
| `keywords.yaml` | 분야별 검색 키워드, 대기업 목록, 이름 바뀐 기관 |
| `bridges.yaml` | 이슈 → 블로그 카테고리 연결 규칙, 방향별 문장, 상담 안내 문구 |
| `directions.yaml` | 환율·금리·증시·예금 오름/내림 판정 낱말 |
| `stages.yaml` | 진행 단계(건의·요구 → 계획 → … → 착공 → 개통) |
| `regions.yaml` | 시·도, 시·군·구, 관광지 |
| `filters.yaml` | 해외 기사·광고·인물 기사·금지 표현 |
| `scoring.yaml` | 점수 배점, 오늘 추천 기준 |
| `packet.yaml` | 소재 패킷 제목 틀·질문·확인할 것·용어 설명·글쓰기 규칙 |
| `sources.yaml` | 수집 소스·간격·호출 상한 |

고친 뒤에는 PowerShell 에서 아래로 검사하세요(틀린 곳을 한국어로 알려 줍니다).

```bash
.venv\Scripts\python.exe -m collector.check_config
```
